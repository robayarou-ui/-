# 給料タイマー

出勤から退勤までをタイマーで記録し、その時間から給料と手取りを計算するWebサイトです。

- 出勤・休憩・退勤ボタンで勤務時間を記録（あとから編集・手入力も可能）
- カレンダーで日ごとの勤務とシフト予定を確認し、日付から勤怠を修正
- 複数の勤務先（掛け持ち）に対応。時給・税区分・保険・色・給料日を勤務先ごとに設定
- よく使うシフトをワンタップで追加、複数の日にまとめて追加
- 月の目標金額と達成度グラフ
- これまでの稼ぎを累計・年別・月別で表示
- 時給、深夜割増、残業割増、交通費から月ごとの支給額を計算
- 所得税（源泉徴収税額表 令和8年分・月額表の甲欄／乙欄）、雇用保険、健康保険・厚生年金、住民税を差し引いて手取りを表示
- データはブラウザの localStorage に保存（サーバー不要）

計算結果は目安です。実際の金額は勤務先の給与明細を確認してください。

## 使い方

ビルドは不要です。フォルダを静的サーバーで配信して開きます。

```sh
npm start   # http://localhost:8000
npm test    # 計算ロジックのテスト（Node.js 20 以上）
```

## 税額表の更新

`js/tax-table.js` は国税庁が公表する月額表（Excel）から生成したデータです。年分が変わったら差し替えてください。
